## The-Scrolling-Olympics
This project was created by Hayden Wood and Samual Hartup for a Hackathon at the University of Lincoln. The theme for the hackathon is "Solve a problem nobody has". 

# Overview
Our problem that were solving is that people are NOT scrolling enough! They must be influenced by this website to scroll more and more, recieving xp and rewards when scrolling. 
Our full stack development project will solve this non-existent problem of people scrolling for too little time.
